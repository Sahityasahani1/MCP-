# Frontend - Autonomous ML Research Agent (AMRA)

Next.js 15 (App Router) + Tailwind CSS + Lucide Icons client application.

## Key Components (Phase 3)
- `ChatInterface.tsx`: Chat container with auto-scroll and markdown rendering.
- `PaperCard.tsx`: arXiv paper card with direct PDF links.
- `DatasetCard.tsx`: Kaggle dataset card with usability score.
- `ApprovalPrompt.tsx`: HITL confirmation button to approve dataset cleaning.
- `DataPreviewTable.tsx`: Visual tabular preview of cleaned CSV and before/after stats.
